PARTIE 3 : Base emploi du temps

1. Format JSON (emploi_du_temps.json)

Structure hiérarchique complète avec :

    • Métadonnées : année académique, semestres, dates vacances/examens
    • Formations : Bachelor 1-3, Master 1-2 avec spécialisations
    • Enseignants : 20 profils avec spécialités
    • Salles : Amphithéâtres, salles de cours, labs informatiques
    • Matières : Codes, noms, ECTS, heures
    • Emplois du temps détaillés : 4 groupes exemples (B1-A, B3-DATA-1, M1-IA-1,

         B3-CYBER-1)
    • Calendrier examens : Dates, horaires, salles, coefficients
    • Dates importantes : Événements académiques et vie étudiante

2. Format CSV (emploi_du_temps.csv)

Version tabulaire plate pour :

    • Import Excel/Google Sheets
    • Traitement par scripts Python/R ou autres
    • Intégration bases de données relationnelles
    • Contient ~100 créneaux de cours pour 8 groupes différents
Données incluses :

Formations couvertes :

    • Bachelor 1 (groupes A, B)
    • Bachelor 2 (groupe A)
    • Bachelor 3 : Développement, Data Science, Cybersécurité
    • Master 1 : IA, Cybersécurité
    • Master 2 : IA
